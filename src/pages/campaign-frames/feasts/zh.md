你可以在战役中使用以下机制，让玩家角色们在游戏过程中采集食材，并在休整期用它们烹饪餐食。

### 食材和风味 {#section-ingredients-flavors}

每种食材由名称和风味组合表示，风味组合包含 1–3 种风味及其相对强度。例如：“菌盖：苦味（1），鲜味（2）。”

共有六种风味，每种风味类型对应一种骰子大小：甜味（d4）、咸味（d6）、苦味（d8）、酸味（d10）、鲜味（d12）和怪味（d20）。风味的强度是一个介于1到3之间的数字。以下列表提供了食材及其风味组合的示例：

- 菌盖：苦味（1），鲜味（2）
- 飞龙舌：酸味（1），鲜味（1），怪味（1）
- 泥怪汁：甜味（1），苦味（2）
- 恐熊肉：鲜味（3）
- 酸蚀龙唾液：酸味（2）
- 洞穴野猪的奶：咸味（1），鲜味（1）
- 愤怒草：苦味（1）
- 食人魔肾结石：甜味（1），怪味（1）

当玩家角色获得一种食材时，将加入其物品栏。玩家角色物品栏中最多可持有的食材数量等于其最高属性值。
当玩家角色使用一种食材烹饪时，掷出与“风味强度”个“风味类型骰子”。

### 采集食材 {#section-harvesting-ingredients}

食材可以从被击败的敌人或队伍所处的环境中获取。

当一只可食用的动物被击败后，玩家角色可以从中采集食材。可采集的食材数量由被击败动物的最大生命点决定，具体见下表：

生命点与食材对照表

| 最大生命点 | 食材数量 |
| - | - |
| 1-4 | 1 |
| 5-7 | 2 |
| 8-11 | 3 |
| 12+ | 4 |

游戏主持人根据叙事细节决定获得哪种风味组合的食材。通常，较弱的敌人主要以甜味、咸味和苦味的风味组合为主，而更强大的敌人则倾向于酸味、鲜味和怪味。

玩家角色也可以通过采集可食用植物和真菌来获取食材。每休息一次，每个玩家角色可以花费 1 希望点，从周围环境中采集食材。游戏主持人根据剧情决定他们获得哪些食材，或者让他们掷出希望骰，然后根据结果获得具有以下风味组合的食材：

环境食材对照表 

| 希望骰结果 | 风味组合 |
| - | - |
| 1-2 | 甜味(1) |
| 3-4 | 咸味 (1) |
| 5-6 | 苦味 (1) |
| 7-8 | 酸味 (1) |
| 9-10 | 鲜味(1) |
| 11-12 | 怪味 (1) |

### 制作盛宴 {#section-make-a-feast}

在以盛宴为核心的战役中，在休整时，玩家们不能通过通常的休整行动来清除压力点、恢复生命点亦或是获取希望点。取而代之的是，他们获得一个新的休整行动：制作盛宴。选择此项行动的每位玩家角色可以从自己的物品栏中取出食材，并将其贡献给队伍的集体大餐，以享用最终盛宴所带来的增益。

#### 准备餐食 {#section-preparing-the-dish}

开始烹饪时，队伍指定一名玩家角色担任厨师。厨师将每种被贡献食材的风味骰合并成一个风味池。例如，一个队伍可能决定用以下食谱制作一份肉排大餐：1份恐熊肉（3d12）、1份菌盖（2d12和1d8）以及1份泥怪汁（2d8和1d4）。这样队伍总共获得 5d12、3d8 和 1d4。

厨师通过掷出风味池中的所有骰子来进行一次备餐掷骰，并将所有相同点数的骰子置于一旁。如果没有相同点数的骰子，则改为厨师移除一枚由他选择的骰子。厨师继续进行烹饪掷骰，直到风味骰池中只剩下一枚骰子，或者所有骰子均已被移除或置于一旁为止。

#### 确定餐食评级 {#section-determining-a-meal-s-rating}

备餐完成后，厨师计算最终的餐食评级。每组匹配的骰子按其匹配的点数计分。例如，一枚d6和一枚d8掷出匹配的3点，则价值3分；一枚d10和一枚d12掷出匹配的4点，则价值4分；而在另一次掷骰中，一枚d8和一枚d20掷出匹配的4点，同样价值4分。厨师将所有得分相加，得出餐食的评级。在本例中，队伍的餐食评级为 11（3 + 4 + 4 = 11）。

#### 享用餐食 {#section-eating-the-meal}

每位参与用餐的玩家角色可以恢复一定数量的生命点、清除一定数量的压力点、并获得一定数量的希望点，只需这三项数字的总和小于或等于餐食评级。例如，如果餐食评级为 11，一名玩家角色可以选择恢复 6 生命点、清除 3 压力点、并获得 2 希望点；而另一名玩家角色则可以选择恢复 5 生命点、清除 2 压力点、并获得 4 希望点。

#### 记录食谱 {#section-recording-the-recipe}

在以盛宴为基础的战役中，玩家应选择一本共用的小型笔记本，按自己喜欢的方式装饰，作为他们的食谱书，并在其中记录他们制作的每一道菜肴的食谱。一份食谱包括以下内容：
- 菜肴的名称、描述以及由玩家构思的备餐方式
- 制作时所使用的食材
- 最终的餐食评级

当队伍烹饪的菜肴与食谱书中某道食谱的风味组合相同时，将数量等同于队伍位阶的指示物添加到该菜肴的风味池中。当厨师被迫从风味池中弃掉一枚骰子时，其可以选择移除一个指示物以替代。
因此，角色们在使用某一相同风味组合制作餐食上实践得越多，该组合的制作难度就越低。

### 高级盛宴 {#section-advanced-feasting}

在你的团队熟悉了基础的盛宴机制后，你可以根据玩家角色对于世界的了解，给予他们机会去寻找并获取某种特定的食材。你也可以创造一些具有额外特性的食材，这些食材应当比普通食材更加稀有，只能从头目或独狼敌人处获取。

特殊食材示例

#### 名称｜风味组合 {#section-profile}

#### 特性 {#section-feature}

- 恐羚颅骨的骨髓

甜味 1、咸味 1、酸味 1

天生神速：在你下次休息前，你的敏捷获得+1加值。

- 圣牛的奶

怪味 1

最后一滴：当你在烹饪时只剩下最后一个骰子时，将其掷出，并将结果加到你的餐食评级中。

- 幽灵蝎毒液

酸味 1、鲜味 1

极具刺激性：若你的风味骰组合中有点数为8或更高的组合，你不能用该食材制成的餐食来清除压力点。

- 死之花

苦味 2

生死一线：使用此食材完成备餐后，若没有任何配对的风味骰组，那么你能恢复 所有 生命点、清除 所有 压力点、并获得 3 希望点。若有任何配对的风味骰组，那么你的餐食评级固定为0，并且你必须进行一次死亡行动。

### 餐厅 {#section-restaurants}

一名玩家角色在休整时可以花费至多 2 把金币从一家附近的餐厅订购餐食，每花费 1 把金币选择下列一项休整行动：清除压力点、恢复生命点或获得希望点。
