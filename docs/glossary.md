# 术语表维护

`data/glossary.md` 是唯一术语表。Editor 支持增删改和直接编辑 Markdown；本地也可用文本编辑器保存，再运行 `build.ps1` 刷新预览，无需 Git。

术语只保留三项：中文名、中文解释、跳转链接。解释和链接可留空，全部条目参与中文正文匹配。英文原文仅用于翻译对照，不自动匹配术语。已有中文解释保持原文，代理不自行补写。

## 分区与条目

可以用任意 `# 分区名称` 分类；`# 术语表` 是文件总标题。每条用 `## 中文名：名称`，解释放在 `### 中文解释` 下。分类是文件结构，不增加字段。Editor 保存时保留分区，新条目默认放进备用区。需要别名时，单独新增一条术语。

```md
# 我的分区

## 中文名：示例术语

- 跳转链接：

### 中文解释

```

重名保留供人工修订。匹配较长名称优先，同等条件按文件顺序处理；同一小节每条仅标注首次出现。

## 在规则正文中屏蔽匹配

行内使用 `[[!文字]]`，不需要 HTML：

```md
这里的 [[!压力点]] 不匹配，后面的压力点正常匹配。
```

标记内可以使用加粗等行内 Markdown，网页只显示内容。屏蔽文字不会消耗该术语在小节内的首次匹配机会。

屏蔽多段内容时使用：

```md
::: no-glossary

这里可以写多段文字，其中的术语都不匹配。

:::
```

标记在编辑器预览与正式阅读页中均不显示。代码中的标记按普通代码显示；未闭合标记按原文字显示。解释及术语表本身由用户人工维护，不设置审核或启停流程。
