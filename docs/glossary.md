# 规则术语与阅读提示

`data/glossary.yaml` 是术语名称、别名、简述和规则目标的来源。简述由本站维护，不替代完整 SRD 正文。读者可在目录下方关闭提示，关闭后链接仍能直达规则；不运行 JavaScript 时同样可用。

首批覆盖 14 个核心术语：希望点、恐惧点、压力点、生命点、伤害阈值、闪避值、护甲槽、护甲值、优势、劣势、隐藏、束缚、脆弱和动作掷骰。

每项必填 `id`（唯一的小写英文标识）、`zh`、`en`、`target`（章节路径）、`anchor` 和双语 `summary`。可选 `aliases.zh`、`aliases.en` 是正文标注使用的别名列表。不要把泛义词、仅用于搜索的俗称、不等价的机制登记为正文别名。

若中英文的实际目标相同，`anchor` 可为字符串；否则使用 `{zh: ..., en: ...}`。**必须核对目标标题和正文，不能只凭锚点拼写判断含义**：历史标题配对使核心机制页部分中文锚点与其英文拼写不同。当前提示链接分别定位两个语言的正确小节，不重命名已有锚点。

构建阶段校验重复 ID、重复名称/别名、缺少简述与不存在的小节。HTML 标注只匹配原始文本，每个标题小节内每种术语仅标注第一次；优先长词，英文按词边界匹配，跳过标题、既有链接、按钮和代码等。生成结果自动携带已转义的简述，不修改 Markdown 原文。

`static/js/terms.js` 渐进增强这些普通链接：鼠标悬停、键盘聚焦或点击显示简述。Tab 可进入完整规则入口和收起按钮，Escape 或点击外部收起。按 Ctrl/Cmd 点击仍遵循浏览器的普通链接行为。偏好仅保存在本地；存储不可用不影响功能。

修改规则正文时同时核对对应简述。在线编辑器继续预览 Markdown 内容，术语链接与提示在发布构建后附加于阅读站。

验证：`python -m pytest tests/test_build_srd.py`、`python scripts/build_srd.py`，然后 `npx playwright test tests/browser/terms.spec.mjs`。
