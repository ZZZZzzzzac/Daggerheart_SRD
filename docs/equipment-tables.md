# 装备查询表格

侧边目录“装备”包含装备规则、主武器、副武器、护甲、物品和消耗品。战斗轮椅位于装备规则的末尾，不单列一级入口。原轮椅页面和装备页旧表格小节链接继续跳转到对应位置，并保持阅读语言。

## 数据维护

规则正文位于 `src/pages/core-mechanics/equipment/{zh,en}.md`。三类装备表分别保存在该目录下的 `primary-weapons`、`secondary-weapons`、`armor` 子目录，仍是普通中英文 Markdown 表格，可通过编辑器修改并预览。

每份源文件保留原表格；阅读页由共用渲染核心合并为一张表。目前主武器 155 条、副武器 37 条、护甲 34 条；`items` 与 `consumables` 子目录分别保存物品与消耗品，各 60 条。没有另存一套装备数据。

主副武器都显示类型列；从每条原文伤害字段提取物理、魔法或物理/魔法类型，英文伤害栏只显示伤害表达式，不再混入 `phy`、`mag`。

物品和消耗品按原有掷骰编号对应中英文，而非按表格位置对应。英文分栏表会展平，空占位列忽略；重复编号或两种语言编号不一致会阻止构建。条目链接使用编号，名称修订不改变链接。中文物品源中粘在同一行的 21、22 号已分行，确保壁虎手套正常收录。

中英文源表按表格与行对应；新增、移除或调整条目顺序时，两种语言应同步调整。构建会检查两边表格数、条目数、位阶和武器类型是否一致，忽略完全空白的表格行。单件链接由位阶和英文名称生成，因此修改英文名称会改变该条目的链接。修改说明、数值或中文名不会改变链接。

## 排序与筛选

- 点列名依次切换升序、降序、取消；可叠加多个排序，按首次点击次序确定优先级，表格上方摘要显示当前顺序。表头只显示排序方向，不显示序号，避免改变列宽。取消某列后，其余排序保留。
- 名称和特性支持中英文文字查找；伤害、阈值使用文字查询，例如 `d10+3`、`11 / 24`，只匹配当前显示的数值。其余字段支持多选。同列选择取并集，不同列条件取交集。
- 物品和消耗品的名称、掷骰编号、效果全部使用文字查询与放大镜入口，不提供多选筛选；也可排序、组合查询和清空。
- 位阶、护甲值按数值排序；距离按近战、邻近、近距离、远距离、极远排序。
- 伤害先比较骰面，再比较固定加值，不计算熟练度或特性的期望伤害；阈值先比较重度，再比较严重阈值。
- 数值排序读取当前语言显示的正文，避免只修改中文数值后仍按英文旧值排序。语言切换保留已选条件和排序。
- “清除筛选与排序”恢复原始顺序；没有匹配条目时显示说明。
- 手机端在表格区域内横向滚动，名称列固定；没有 JavaScript 时仍能阅读完整表格。

## 构建与搜索

`static/js/equipment-core.mjs` 负责正文与编辑预览共用的表格渲染。`static/js/equipment-table.mjs` 提供阅读端排序筛选。`scripts/equipment_catalog.py` 将单件装备接入现有双语搜索，并在装备规则页保留旧小节的跳转标记。

回归测试覆盖双语条目数、跨语言身份、原小节锚点、排序语义、组合筛选、全站搜索、旧链接、编辑预览、无脚本阅读及桌面和手机布局。
