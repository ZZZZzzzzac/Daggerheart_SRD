# 核心规则锚点迁移

本次修复范围为核心机制页与创建角色页。历史上按标题序号配对中英文，导致增减标题后中文标题与英文片段名错位。明确写出的标题锚点现在按各自语言独立读取，不再依靠位置配对；同一语言重复锚点仍会阻止构建。

受影响小节使用含义明确的 `rule-…` 锚点，中英文对应同一个概念。例如：

- 生命点与伤害阈值：`rule-hit-points-damage-thresholds`
- 压力点：`rule-stress`
- 闪避值：`rule-evasion`
- 攻击掷骰：`rule-attack-rolls`
- 创建经历：创建角色页的 `rule-step-7-create-your-experiences`

核心机制里原有的中文 `#stress` 指向阈值，英文 `#stress` 指向压力。不能把两个历史含义直接合成一个，所以新链接另用 `rule-` 前缀，旧片段由 `static/js/legacy-anchors.mjs` 分语言兼容。阅读器进入旧链接后，会按当前阅读语言转换为明确的新片段；之后切换语言仍停留在同一概念。无脚本时保留中文旧片段的页面落点。

为保证两种语言有对应落点，将中文原有“希望点”“选择你的武器”行，以及英文原有三个希望点用途行提升为小标题，没有改写其解释正文。现有术语表和正文内指向这两个页面的绝对站内链接已更新。

其他页面没有在此次迁移中全面重命名锚点。新增小节应填写明确、按语义对应的中英文锚点，避免再次按序号推断含义。
