# 领域卡查询

原 `/SRD/domain-cards/` 页面提供 189 张领域卡。Markdown 仍为唯一规则来源，editor 共享 Render Core 渲染。
无需新增语法：四级标题定义卡名和稳定锚点，其后加粗行定义等级、领域、属性及回想费用，余下 Markdown 为规则正文。

页面复用敌人/环境的固定 26rem 卡宽、下拉多选、完整/紧凑滑动开关、全文短语搜索高亮、悬浮预览和 URL 状态。
可组合多选等级、领域、属性、回想费用。参数 q、tier（等级）、type（领域）、cardtype、recall、view 保存筛选。
旧卡名锚点继续可用；卡名链接为 #domain-原锚点。中英文切换保留筛选。

卡面参考 PbDH 领域模板：深色名称栏、中英文名称层级、领域/等级/属性/回想四格属性与完整规则正文。
卡片正文可显示术语提示，标题和属性栏不启用。构建会校验双语卡片锚点与字段格式。
