# 中英文小节对应与搜索锚点

## 对应规则

同一页面内，含义相同的小节使用同一个显式 `{#anchor}`。小节身份由 `path + anchor` 决定，与标题位置、标题层级和段落数量无关。原文与译文仍分别保存在各自 Markdown 中，不新增运行时翻译映射表。

本次核对全部 17 对页面，修正职业、领域介绍、主持游戏、战役框架，以及敌人与环境卡内部的错位锚点。种族页两处、主持页一处数字开头的旧锚点曾被重复拼接，已改为有效且固定的锚点。正文措辞和段落排布保持原样。

敌人与环境整张资料卡继续使用已有 `adversary-<id>` / `environment-<id>` 搜索链接；卡内标题使用该卡身份派生的锚点，避免按排列顺序关联。领域卡沿用已有正确锚点。

## 旧链接

错位的旧 ID 在两种语言下可能原本就指向不同内容，因此不能直接把旧 ID 重新分配给另一个标题。例如旧中文 `#arcana` 指向“利刃”，英文则指向“ARCANA”。

新小节使用独立的 `section-…` 锚点；`static/js/legacy-anchors.mjs` 保留每种语言的旧 ID → 新 ID。打开旧链接时，先归一化到原语言下的小节，再按新锚点切换语言。站内术语链接已更新，术语名和解释未修改。

这张历史兼容表仅用于旧链接，不参与新搜索的双语匹配。

## 索引验证

之前索引仅收录一至三级标题，会漏掉四级及以下小节，也会因两种语言的标题层级不同而缺少一侧记录。现在每个小节独立收录，正文片段截止下一个标题；目录的展示层级保持原样。

已使用实际生成的搜索索引验证：先在源语言搜索，再以命中项的 `path + anchor` 查找目标语言记录，可得到：

| 查询 | 对应结果 | 小节锚点 |
| --- | --- | --- |
| Stress / 压力点 | 压力点 / STRESS | `core-mechanics#rule-stress` |
| ARCANA | 奥术 | `core-resources/domains#section-arcana` |
| 利刃 | BLADE | `core-resources/domains#section-blade` |
| Druid / 德鲁伊 | 德鲁伊 / DRUID | `core-resources/classes#section-druid` |
| RUNE WARD | 符文护符 RUNE WARD | `domain-cards#rune-ward` |
| 酸液掘地者 | Acid Burrower | `adversaries-and-environments/adversary-data#adversary-acid-burrower` |
| 1d12 Objective | 1d12 目标 | `running-a-game#section-objective-d12` |

当前生成索引包含中文 888 条、英文 894 条，其中 874 组有共同键。这里包含已有资料库对 10 张缺少英文原文的敌人卡所做的中文回退，不能把这 10 组称为已有完整双语正文。

搜索弹窗同时检索两种语言，再按共同键选择结果显示语言的标题、摘要和链接，并合并重复结果。中文结果由英文命中时标注“匹配原文”，附原文小节名；英文显示模式反向标注中文命中。两边都命中时使用较高得分，同分优先显示语言。显示语言按钮只切换结果语言，不限制查询语言，点击结果会保持所选阅读语言。

## 未强行配对的标题

中文有 14 个、英文有 20 个索引标题没有另一语言的同键记录：

- 领域介绍：中文的职业领域、领域卡解析、配置与宝库等 11 个标题；英文的九领域总引导标题。
- 职业：中文的野兽形态位阶 3 标题；英文的 14 个施法属性标题、德鲁伊关系、术士领域。其中施法属性在中文是加粗文字，并非缺少译文。
- 主持游戏：中文的难度总标题；英文的开篇介绍和命运掷骰示例标题。部分对应文字存在，但未单列标题。
- 战役框架：中文总标题；英文复杂度标题，中文复杂度为正文。

这些记录保留本语言身份。另一语言命中没有对应小节时，结果回退到显示语言的章节入口，并明确标注“定位到中文章节”（英文模式为相应英文说明），不展示无关中文小节的摘要。同一章节的多条回退结果合并。搜索不会以序号或相邻标题猜测另一语言的目标；需要更细的互搜覆盖时，可把已有对应文字整理成同键小节。真正缺少的正文不能通过搜索映射补出。
