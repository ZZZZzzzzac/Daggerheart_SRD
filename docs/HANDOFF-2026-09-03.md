## 当前完成状态

- 阅读站已经改为双语 HTML SRD：默认中文、左侧 CHM 式折叠目录、面包屑、前后页、深浅主题、正文搜索和站内勘误。
- 桌面端目录常驻；移动端使用抽屉。目录最深到小节，没有右侧小节目录。
- 搜索覆盖标题、小节和正文，标题与小节命中优先；界面不显示命中次数。
- 编辑器、反馈后台和管理接口使用同一组 Basic Auth；阅读站和读者勘误保持公开。正式密码由 nginx 密码文件管理，不写入仓库。
- 编辑器固定浅色，使用与阅读站相同的顶部栏和左侧目录。顶部编辑工具替代阅读模式的搜索框，正文区域为 Markdown 编辑区和正式规则预览区。
- 从正文页的“管理员编辑”进入时，URL 会携带当前页面路径并自动打开对应编辑内容。直接打开编辑器时会尝试来源页面，无法判断时打开目录第一篇。
- 编辑器左侧目录与阅读站共享 `data/srd.yaml` 生成的顺序和中文标题；点击章节会进入对应编辑地址，未保存内容仍受离开警告保护。
- Markdown 预览与正式构建共用渲染规则。表格恢复原生表格布局，宽表在独立区域横向滚动，不再丢失后半部分。
- 保存流程包含版本冲突检查、临时候选构建、完整校验、一次性替换、本地 Git 版本和后台 GitHub 同步。
- 反馈进入 SQLite 收件箱，不通过 GitHub；管理员后台可查看、备注、改变状态和导出。

- 当前分支：`master`。
